One-time setup needed

To connect to your YouTube account, you need a credentials file from Google. Here's how to get it:

  1. Go to Google Cloud Console, create a project, and enable the YouTube Data API v3
  2. Go to Credentials, click Create Credentials, and choose OAuth client ID (Desktop app)
  3. Download the file and save it as client_secret.json in the same folder as app.py
  4. Come back here and refresh the page
